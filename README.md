# Yana18 · Подарочное приложение для Яны на iPhone

Нативное iOS-приложение (SwiftUI) с автоматической облачной сборкой файла `.ipa` через **GitHub Actions** на виртуальной машине macOS.

---

## Что внутри
- **Главный экран**: вращающаяся радужка глаза («Око Вселенной») с роскошной золотой каймой, отступом и жестом удержания для разблокировки.
- **Главы I–VI**:
  - Интерактивная монограмма 18
  - Живой хронометраж времени с 11.11.2008 (дни, часы, минуты, секунды)
  - 18 сокровенных причин любви со всеми 18 фотографиями
  - Bento-галерея с 6 кадрами (включая совместное фото с мороженым)
  - Стек интерактивных карточек пожеланий
  - Письмо любимой Яне от Мандаринки с тайной интерактивной звездой
- **Фоновая музыка**: песня Барбариков с фоновым зацикливанием и кнопкой вкл/выкл.
- **Шрифты**: Cormorant Garamond, Manrope, Caveat.

## Как собрать файл .ipa за 2 минуты через GitHub Actions

### Шаг 1. Создайте репозиторий на GitHub
1. Зайдите на сайт [github.com](https://github.com) в свой аккаунт (или зарегистрируйтесь бесплатно).
2. Нажмите кнопку **New repository** (Новый репозиторий).
3. Назовите его, например, `Yana18-iOS`. Выберите **Private** (Личный) или **Public** и нажмите **Create repository**.

### Шаг 2. Загрузите файлы проекта
1. На странице созданного репозитория нажмите ссылку **uploading an existing file** (Загрузить существующие файлы).
2. Перетащите в окно браузера все папки и файлы из этой папки (`.github`, `Sources`, `Resources`, `project.yml`, `README.md`).
3. Нажмите внизу зеленую кнопку **Commit changes**.

### Шаг 3. Скачайте готовый .ipa
1. Перейдите во вкладку **Actions** вверху страницы репозитория.
2. Вы увидите запущенную сборку **Build iOS IPA** на облачном сервере macOS.
3. Примерно через 1–2 минуты сборка завершится с зеленой галочкой.
4. Нажмите на название завершенной сборки, прокрутите страницу вниз до блока **Artifacts** и нажмите **Yana18-iOS-IPA**.
5. Скачается архив с готовым файлом `Yana18.ipa`!

## Как установить .ipa на iPhone

Самый быстрый и удобный способ для Windows:
1. Скачайте бесплатную программу **Sideloadly** ([sideloadly.io](https://sideloadly.io/)).
2. Подключите iPhone к компьютеру кабелем (нажмите «Доверять этому компьютеру» на экране айфона, если появится запрос).
3. Запустите Sideloadly, перетащите скачанный `Yana18.ipa` в окно программы.
4. Введите свой Apple ID (для бесплатной автоматической подписи Apple) и нажмите **Start**.
5. Через 30 секунд приложение появится на экране iPhone с иконкой «Яна · 18»!
6. На iPhone перейдите в: **Настройки → Основные → VPN и управление устройством** и нажмите «Доверять».
